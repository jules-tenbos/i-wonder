# Notes

## Storyline

### 1. The structural base (P0/P1)
- Being implies language, language is relational
- Broad sense: all relational activity, not just human communication

### 2. Language binds, not represents
- Brandom/inferentialism: meaning as position in network of moves
- Language as commitment, not representation
- Caution: Brandom is anthropocentric, P4 keeps this honest

### 3. Contingency is structural
- Language as contingent as the creation that brings it
- Rorty's contingency: no escape through rigour

### 4. Conception and realisation
- To understand = to create the language
- Unrealised stays outside reality
- Conceiving the future is creating it — but must be sustained

### 5. The personal
- Every creation specific → language inherently personal
- Not a defect, the structure

### 6. Structural pluralism (P4/P5)
- Contingency → no privileged language → equal standing
- Plurality as fertile ground, creative engine
- Foreshadows interrelational pluralism

### 7. Bridge to historicity
- Language so far could be static
- What happens when it leaves a trace? Next post.
