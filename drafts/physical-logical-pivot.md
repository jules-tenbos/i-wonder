# Notes

## Storyline

### 1. Open with the discovery
- We had carrier/meaning as an AVRO design principle
- Then noticed it was deeper — physical/logical, the same axis the three pillars sit on
- Not designed — found

### 2. AVRO already had it
- Logical types, namespaces, reader/writer resolution
- The meaning machinery was latent
- Double core: engineering and meaning, both always present

### 3. "Is like" as the decoupling principle
- The physical doesn't have to BE the target format, it has to be READABLE AS
- Data conformance, version compatibility, schema evolution — all the same test
- Always at the point of contact, never at the point of storage
- One principle, every level

### 4. Category theory as the formal backbone
- "Is like" isn't loose — every "readable as" is a morphism
- Morphisms compose (transformation chains), preserve structure, have measurable loss
- Functors map between categories (physical → logical)
- Natural transformations map between different readings of the same data
- Formal properties discovered in what the architecture already does

### 5. What this opens
- A string with a logical type declaring its meaning language
- Concept vocabularies carried with the data
- "Can I read it as" extended from structural conformance to conceptual extraction

### 6. XPath goes deeper
- Same path expression, same traversal, now reaching into meaning
- The fabric gets smarter as you add schemas and logical types, not machinery

### 7. Git becomes narrative
- The commit message is the primary record
- History is a conversation with your own past
- Consolidation is editorial, not mechanical

### 8. The activation layer
- Without HAICC, the logical layer is an annotation doing nothing
- Cognition behind the RPC boundary makes the logical operational
- Same schema contract, invisible resolution

### 9. Close with meaning loss
- Every transformation between languages loses something
- The loss profile is data
- Friction points where mapping doesn't work are where languages genuinely differ
- Not failure — P4 making itself visible

## Key theme
The "is like" / "readable as" principle decouples physical from logical at every level. Each section is another expression of the same principle.
