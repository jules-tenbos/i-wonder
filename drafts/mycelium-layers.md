# Notes

## Storyline

### 1. Stacking without prescribing
- The fabric provides the layering mechanism, not the layers
- Projections, indexes, process state — all instances of the mechanism, defined by protocol libraries
- The fabric grows in capability without changing the base

### 2. Safe mode as recovery guarantee
- Whatever the layers above do, the raw physical layer is always reachable
- Architecture of absence applied to recovery
- The floor is always solid

### 3. Read modes as identity
- A subject reality defines its layer stack as part of what it is
- What you see is determined by the layers you've constituted
- Different subjects, same data, different experience

### 4. Synchronisation as data observation
- Derived layers watch their sources
- Same trigger model as the process layer
- Immediate, batched, or on-demand — no orchestration

### 5. Replication and interaction
- Replication as a layering concern
- Data state propagation as the default interaction
- Decoupled, reactive, no messages between processes

## Connects to
- Fabric — layers stack on the static structure
- XPath — layers discovered during traversal
- Process — synchronisation uses the process layer's trigger model
- Protocol — layer types defined by protocol libraries
