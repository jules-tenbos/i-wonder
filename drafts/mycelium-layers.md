### Key angles for narrative

- **Stacking without prescribing** — the fabric provides the layering mechanism, not the layers. Projections, indexes, process state — all instances of the mechanism, defined by protocol libraries. The fabric grows in capability without changing the base.

- **Safe mode as recovery guarantee** — whatever the layers above do, the raw physical layer is always reachable. The floor is always solid. This is architecture of absence applied to recovery.

- **Read modes as identity** — a subject reality defines its layer stack as part of what it is. What you see is determined by the layers you've constituted. Different subjects, same data, different experience.

- **Synchronisation as data observation** — derived layers watch their sources. Same trigger model as the process layer. Immediate, batched, or on-demand. No orchestration.

- **Replication and interaction** — replication as a layering concern. Data state propagation as the default interaction. Decoupled, reactive, no messages between processes.

### Connects to

- Fabric — layers stack on the static structure
- XPath — layers discovered during traversal
- Process — synchronisation uses the process layer's trigger model
