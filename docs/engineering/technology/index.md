# Technology

The external platform SPLectrum builds on — runtime and modules SPLectrum depends on but does not itself author. The boundary is permeable: a platform dependency becomes constitutive if it needs modification.

## Platforms

- [Bare](bare/) — the Holepunch JavaScript runtime, the implementation platform.
- [bare-for-pear](bare-for-pear/) — community fork modules adapted for Bare (avsc, avsc-rpc, git, rpc-server).
