# Pear

Pear is Holepunch's peer-to-peer application runtime and deployment platform: applications are staged, distributed, and updated directly between peers, with no central servers and no app store. It builds on [Bare](/engineering/infrastructure/bare/) and the [P2P building blocks](/engineering/infrastructure/p2p/).

> **Mid-evolution.** Pear is moving from the original `pear run` CLI model toward an embeddable `pear-runtime` library that applications include directly. This page predates that transition, so treat the live Holepunch docs as the current truth until it is rewritten.
