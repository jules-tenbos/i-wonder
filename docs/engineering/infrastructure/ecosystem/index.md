# Ecosystem

A curated, health-aware view of what the wider community is building on the Bare + P2P + Pear stack — applications, tools, and libraries that depend on it. The aim is a useful map, not a directory: entries note roughly how active and production-ready a project is, since freshness varies and any listed project can go quiet.

Listing here is not endorsement. Each entry links out to a community project maintained by others; assess fitness for your own use.

This is a holding page. Entries will be added over time, health-tiered rather than dumped as a flat link list.
