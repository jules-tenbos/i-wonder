## The three pillars

- [SPLectrum](splectrum/) — the language fabric. Metadata on the data fabric. Identifier grammar, protocols, personas.
- [HAICC](haicc/) — human-AI creative collaboration, the cognition fabric. Metadata on the data fabric. Process models, personas.
