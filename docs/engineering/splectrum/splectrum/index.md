The language pillar. Metadata on the data fabric — where protocols (language game units) are composed into personas (language game roles). Protocols here are *data transformations*: the relational of P1 expressed as transformations of data state, not as function calls.

Language is SPLectrum's most important component. Over time, this is the pillar that will grow to stand out across all the work.
