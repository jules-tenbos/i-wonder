# Implementation

The physical how — repositories, dependencies, supply chain, tooling, distribution. How the codebase is structured, what it carries, what it reaches for, and how it gets to the peer.

Distinct from the engineering design (what is built and why) and from the philosophical framework (what it means). Implementation is where the design meets the machine.
