# SPL Seed

The vocabulary of the [seed](/seed/). Three layers: the seed's own terms — from the principles and the seed pages that extend them — a page vocabulary drawn from the philosophical seed page, and an engineering variant that translates seed terms into software.

## Original

The seed's own vocabulary — terms as they appear in [the original principles](/seed/original/) and the seed pages that extend them.

<span id="being">**Being**</span> — That which is different from *the other* — a unit of difference.

<span id="cognition">**Cognition**</span> (P2) — The process of acquiring knowledge and understanding through experience. The process within P2: always already running — no separation between being in language, experiencing reality, and making sense of it; each subject runs its own. See [the seed and Cognition](/seed/cognition/).

<span id="convergence">**Convergence**</span> (P3) — Reaching a highly similar state of language across subjects — creates shared reality, the source of subjective objectivity.

<span id="equal-standing">**Equal standing**</span> (P4) — No language has dominion over another. The content of one language is not superior or inferior to another's.

<span id="indirect-interaction">**Indirect interaction**</span> (P3) — Subject-to-subject relating, never direct: like a relay where the baton — what is shared — is passed between subjects, each interacting with it in their own language context and shaping it before passing on. The structural form of being-with-others — the everyday sense of "experiencing the world in relation to others."

<span id="knowledge">**Knowledge**</span> — The insight factor of a subject's reality.

<span id="language">**Language**</span> — A language game unit — one specific interaction pattern.

<span id="reach">**Reach**</span> (P1) — The relations a language holds.

<span id="reality">**Reality**</span> — The totality of a subject's experience.

<span id="seed">**Seed**</span> — SPLectrum's foundational axiomatic base; six principles on the creation and dynamics of language, subjects and relation.

<span id="shared-reality">**Shared reality**</span> — The reality that a group of subjects has converged on (through language).

<span id="six-principles">**Six principles**</span> — The axiomatic base of SPLectrum.

<span id="subject">**Subject**</span> — Entity that has the current POV, holding the reference point for relational interactions.

## Philosophical — page vocabulary

The vocabulary as it appears on [the seed and philosophy](/seed/philosophical/). These are terms drawn from external thinkers, used on that page to position the seed in philosophical traditions.

<span id="differentiation">**Differentiation**</span> (P0) — The act through which being comes into existence ([Fichte](https://plato.stanford.edu/entries/johann-fichte/)). The cut that separates being from not-being.

<span id="always-already-disclosed">**Always already disclosed**</span> (P0) — Being is not something that exists and then gets disclosed; it is in a world from the start ([Heidegger](https://plato.stanford.edu/entries/heidegger/)).

<span id="sublation">**Sublation**</span> (P0) — The dialectical mechanism through which each new determination supersedes and preserves prior ones ([Hegel](https://plato.stanford.edu/entries/hegel/)).

<span id="determinatio-est-negatio">**Determinatio est negatio**</span> (P0) — Every determination requires what it negates ([Spinoza](https://plato.stanford.edu/entries/spinoza/)).

<span id="actual-occasion">**Actual occasion**</span> (P0, P5) — Unit of process; each occasion concresces from prior ones ([Whitehead](https://plato.stanford.edu/entries/whitehead/)).

<span id="language-game">**Language game**</span> (P1) — Meaning arises from use, not from definitions ([Wittgenstein](https://plato.stanford.edu/entries/wittgenstein/)).

<span id="differential-sign">**Differential sign**</span> (P1) — A sign has no content in itself, only in relation to other signs in the system ([Saussure](https://plato.stanford.edu/entries/saussure/)).

<span id="body-as-medium">**Body as medium**</span> (P2) — The body is the medium through which experience is given ([Merleau-Ponty](https://plato.stanford.edu/entries/merleau-ponty/)).

<span id="view-from-nowhere">**View from nowhere**</span> (P2) — The perspective the seed denies: no outside view, no observer-free reality.

<span id="community-of-inquirers">**Community of inquirers**</span> (P3) — Truth as long-run convergence of inquiry ([Peirce](https://plato.stanford.edu/entries/peirce/)).

<span id="communicative-action">**Communicative action**</span> (P3) — Shared understanding emerges through speech oriented to mutual understanding ([Habermas](https://plato.stanford.edu/entries/habermas/)).

<span id="metanarrative">**Metanarrative**</span> (P4) — An overarching account that would subordinate other language games. The seed denies any metanarrative ([Lyotard](https://plato.stanford.edu/entries/lyotard/)).

<span id="ways-of-worldmaking">**Ways of worldmaking**</span> (P4) — Multiple versions rather than one true description ([Goodman](https://plato.stanford.edu/entries/goodman/)).

<span id="process-philosophy">**Process philosophy**</span> (P5) — Creativity as the ultimate category ([Whitehead](https://plato.stanford.edu/entries/whitehead/)).

<span id="creative-evolution">**Creative evolution**</span> (P5) — Evolution as ongoing creative becoming ([Bergson](https://plato.stanford.edu/entries/bergson/)).

## Engineering — variant

The seed vocabulary as it appears in [the applied seed — engineering](/seed/engineering/). Translations and extensions of original seed terms.

<span id="data-entity">**Data entity**</span> — Engineering term for [being](#being). A data unit with object structure: data alongside associated functionality.

<span id="data-fabric">**Data fabric**</span> — The medium that propagates data state across owners.

<span id="data-owner">**Data owner**</span> — Engineering term for [subject](#subject). Borrowed from microservices: the holder of a set of data entities.

<span id="data-repository">**Data repository**</span> — Where an owner's data state lives (git repo).

<span id="data-state">**Data state**</span> — Engineering term for [reality](#reality).

<span id="data-world">**Data world**</span> — The totality of data state across the data fabric.

<span id="data-world-subview">**Data world subview**</span> — A partial view of the data world made available to an owner.

<span id="operator">**Operator**</span> — An API method within a protocol.

<span id="persona-eng">**Persona**</span> — A structured set of protocols — a language game role.

<span id="protocol">**Protocol**</span> — Engineering term for [language](#language). A software API with meaning constraint.

<span id="shared-data-state">**Shared data state**</span> — Engineering term for [shared reality](#shared-reality). Visibility is sharing.
