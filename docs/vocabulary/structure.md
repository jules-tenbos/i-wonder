# The structure of vocabulary

Language is a collection of concepts and the ways they interact. Concepts are bounded units — entities, beings with their own contents. Interactions are the relations between them: definitional, derivational, cross-referential, idiomatic, narrowing, borrowing, and others. A language, in any bounded context, is both: concepts and the relations that operate on them.

**Vocabulary is the set of concepts within a bounded context.** The node set of a language game, before the relations. A full account of a language needs both vocabulary and the relations that operate on it, but vocabulary is the layer that can be catalogued as a bounded set and used as the anchor for further work.

## Scale-free composition

Concepts, vocabularies, and language games are beings at different scales of the same structure.

- A **concept** is a being with contents — the words needed to define it, a small-scale vocabulary of its own.
- A **vocabulary** is a being with concept-contents — a bounded set of concepts, each itself a being.
- A **language game** is a being with a vocabulary in use — concepts operating through relations, with players, rules, and a context of deployment.

Same ontology throughout; what varies is scale, function, and relation to other beings. The [seed vocabulary](/vocabulary/splectrum/seed/) names the type: *Being → Entity*, inside is being, surface is language. The compositional structure nests; the unit type does not change.

## A category-theoretic view

The decomposition maps cleanly onto category theory:

- **Concepts** → objects.
- **Vocabulary** → the object set of a category, Ob(C), per bounded context.
- **Relations** → morphisms. Multiple kinds (definitional, derivational, idiomatic, cross-referential) coexist.
- **A language within a bounded context** → a category.
- **Cross-context mappings** (how one language game's terms map into another's) → functors between categories.

Category theory isn't imposed here; it's the formalism the working description naturally invites. Formal treatment is an open research direction.

## Borrowing without appropriation

Some terms SPLectrum uses have clear origins outside the project. "Language game," for instance, is Wittgenstein's. When SPLectrum uses it, it borrows — the term stays tagged to its origin in vocabulary work. Borrowing doesn't transfer ownership, however deeply the concept gets operationally adopted. The discipline keeps the project's lineage legible and avoids quiet appropriation.
