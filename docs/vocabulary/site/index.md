# This Web Site

Analysis of word use on specific pages is done for two specific purposes:

- **Language research** — how vocabulary shifts between pages, zoom levels, and personas; how the site's language games interrelate.
- **Writing standard** — supporting better writing practice for human and AI authors, giving them a concrete object to check against.

The [how shadow pages are made](how-shadow-pages-are-made/) page explains the process of extraction.
