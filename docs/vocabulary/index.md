# Vocabulary

Concepts made explicit, one vocabulary per language game. Making the words of a game explicit lets the game be studied, compared, and kept free of implicit drift.

A first scaffold growing SPLectrum's own vocabularies, and a second analysing word use on selected pages of this site.

- [SPLectrum](/vocabulary/splectrum/) — building up SPLectrum's own language catalogue.
- [Wittgenstein](/vocabulary/wittgenstein/) — terms SPLectrum borrows from Wittgenstein.
- [This Web Site](/vocabulary/site/) — examining vocabulary use on selected pages of this site.

For the structural account — concepts, relations, vocabulary, language — see [Structure](/vocabulary/structure/).
