# Seed vocabulary — Engineering

The seed vocabulary as it appears in [the applied seed - Engineering](/seed/engineering/). Translations and extensions of [original-seed terms](original).

**Data entity** — Engineering term for [being](original). A data unit with object structure: data alongside associated functionality.

**Data fabric** — The medium that propagates data state across owners.

**Data owner** — Engineering term for [subject](original). Borrowed from microservices: the holder of a set of data entities.

**Data repository** — Where an owner's data state lives (git repo).

**Data state** — Engineering term for [reality](original).

**Data world** — The totality of data state across the data fabric.

**Data world subview** — A partial view of the data world made available to an owner.

**Operator** — An API method within a protocol.

**Persona** — A structured set of protocols — a language game role.

**Protocol** — Engineering term for [language](original). A software API with meaning constraint.

**Shared data state** — Engineering term for [shared reality](original). Visibility is sharing.
