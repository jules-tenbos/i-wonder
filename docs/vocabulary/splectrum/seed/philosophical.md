# Seed vocabulary — Philosophical

The seed vocabulary as it appears in [the seed and Philosophy](/seed/philosophical/).

**Differentiation** (P0) — The act through which being comes into existence ([Fichte](https://plato.stanford.edu/entries/johann-fichte/)). The cut that separates being from not-being.

**Always already disclosed** (P0) — Being is not something that exists and then gets disclosed; it is in a world from the start ([Heidegger](https://plato.stanford.edu/entries/heidegger/)).

**Sublation** (P0) — The dialectical mechanism through which each new determination supersedes and preserves prior ones ([Hegel](https://plato.stanford.edu/entries/hegel/)).

**Determinatio est negatio** (P0) — Every determination requires what it negates ([Spinoza](https://plato.stanford.edu/entries/spinoza/)).

**Actual occasion** (P0, P5) — Unit of process; each occasion concresces from prior ones ([Whitehead](https://plato.stanford.edu/entries/whitehead/)).

**Language game** (P1) — Meaning arises from use, not from definitions ([Wittgenstein](https://plato.stanford.edu/entries/wittgenstein/)).

**Differential sign** (P1) — A sign has no content in itself, only in relation to other signs in the system ([Saussure](https://plato.stanford.edu/entries/saussure/)).

**Body as medium** (P2) — The body is the medium through which experience is given ([Merleau-Ponty](https://plato.stanford.edu/entries/merleau-ponty/)).

**View from nowhere** (P2) — The perspective the seed denies: no outside view, no observer-free reality.

**Community of inquirers** (P3) — Truth as long-run convergence of inquiry ([Peirce](https://plato.stanford.edu/entries/peirce/)).

**Communicative action** (P3) — Shared understanding emerges through speech oriented to mutual understanding ([Habermas](https://plato.stanford.edu/entries/habermas/)).

**Metanarrative** (P4) — An overarching account that would subordinate other language games. The seed denies any metanarrative ([Lyotard](https://plato.stanford.edu/entries/lyotard/)).

**Ways of worldmaking** (P4) — Multiple versions rather than one true description ([Goodman](https://plato.stanford.edu/entries/goodman/)).

**Process philosophy** (P5) — Creativity as the ultimate category ([Whitehead](https://plato.stanford.edu/entries/whitehead/)).

**Creative evolution** (P5) — Evolution as ongoing creative becoming ([Bergson](https://plato.stanford.edu/entries/bergson/)).
