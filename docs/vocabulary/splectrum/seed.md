# Seed vocabulary

This page contains the seed vocabulary in use across the different areas of SPLectrum.

<span id="being">**Being**</span> — That which is different from *the other* — a unit of difference.

<span id="convergence">**Convergence**</span> (P3) — Reaching a highly similar state of language across subjects — creates shared reality, the source of subjective objectivity.

<span id="data-state">**Data state**</span> (engineering) — Engineering term for [reality](#reality).

<span id="data-world">**Data world**</span> (engineering) — The totality of data a subject can potentially relate to.

<span id="entity">**Entity**</span> (engineering) — Engineering term for [being](#being).

<span id="equal-standing">**Equal standing**</span> (P4) — No language has dominion over another. The content of one language is not superior or inferior to another's.

<span id="language">**Language**</span> — A language game unit — one specific interaction pattern.

<span id="owner">**Owner**</span> (engineering) — Engineering term for [subject](#subject).

<span id="persona">**Persona**</span> (engineering) — A structured set of protocols — a language game role.

<span id="protocol">**Protocol**</span> (engineering) — Engineering term for [language](#language).

<span id="reality">**Reality**</span> — The totality of relations and interactions available to a subject.

<span id="seed">**Seed**</span> — SPLectrum's foundational axiomatic base; six principles on the creation and dynamics of language, subjects and relation.

<span id="shared-data-state">**Shared data state**</span> (engineering) — Engineering term for [shared reality](#shared-reality).

<span id="shared-reality">**Shared reality**</span> — The reality that a group of subjects has converged on (in language).

<span id="six-principles">**Six principles**</span> — The axiomatic base of SPLectrum.

<span id="subject">**Subject**</span> — Entity that has the current POV, holding the reference point for relational interactions.

<span id="subject-reality">**Subject reality**</span> (engineering) — The data picture of an owner's subject matter — the dynamic data state Mycelium makes visible to the owner.
