# Upcoming Blog Posts

This directory contains blog posts currently in active development. These are copied/derived from the main `ideas/` repository when ready to be written.

## Purpose

- **Active development** of specific blog posts
- **Focused writing** with publication in mind
- **Draft refinement** and structure development
- **Bridge** between ideas and published posts

## Workflow

1. **Copy relevant material** from `ideas/` when ready to write
2. **Develop and structure** the post
3. **Refine** content to ~600 words, "light but deep" tone
4. **Move to main blog/** when ready to publish
5. **Update references** in `ideas/` to track connection

## Guidelines

- Aim for ~600 words per post
- Maintain "light but deep" accessible tone
- Include analogies where helpful
- Connect to previous posts when relevant
- Keep philosophical without being academic
