# Post vs ref lib — bar is non-contradiction

The relationship between a blog post and its corresponding ref lib page is governed by **non-contradiction**, not coverage parity or register match. A post can do partial coverage, take a different angle, use a different register, or skip moves the ref lib makes. None of that is drift; both expressions can hold.

## Why

Blog posts are conversational pieces — different register, different goals from ref lib pages. Forcing parity flattens the differences that make each format do its job. Jules has framed this directly: *"Post should not contradict, that is all. It can do partial, something else, it is a conversational piece."*

## How to apply

When evaluating a post against an updated ref-lib page on the same topic:

- Flag only places the post asserts something the page contradicts.
- Do not flag: different framings that are compatible; ref-lib moves the post simply doesn't make; richer/colder ref-lib language vs. warmer/looser post language; supplementary post content (gradients, examples, asides) that have no page counterpart.
- "Drift" is not a problem if both can be true at once. Two compatible expressions both hold.
